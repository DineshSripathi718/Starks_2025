Variables

Variables are used to hold the data temp in memory.

Rules :

  • We shouldn't start variable name with numbers
  • We shouldn't use special characters except _ and $ when declaring variables
  • We shouldn't use the keywords as variable names

Declaration

  • Let : (ES6)
    we can assign/ change value to the variable at any point during execution.
  • const : (ES6)
    we can assign value at the time of declaring the variable and we can't override the value.
  • var :
    we can assign/ change value to the variable at any point during execution.

DataTypes :

Used to define the type of data we are storing inside the variable

List of datatypes

  • numbers - standard numbers and decimal
  • string - collection of alphabets and special characters
  • boolean - true or false
Javascript it is a dynamically typed lang. It will automatically assign datatype to the variable based on the store value inside it

Scope of variable :

The range which we can access the variables.

  1. Global Level :
    let a = 5;
  2. Block level/ Local level : 
                                    for(let i = 1; i <= 4; i ++){
                                    console.log(i);
                                }
                                console.log(i); //we can access i as it is outside the scope

                                                    let a = 5;

conditional statements

perform an operation based on condition. It can handle multiple conditions with less complexity

  1. Simple If
    It will only work when the condition if true. 
                            syntax : 
                            if(condition){
                                //block of statements
                            }
  2. if else :
    executes the if statment if it is true or else it will execute else statements 
                        syntax : 
                        if(true){
                            //block of if statements
                        }else{
                            //block of else statements
                        }
  3. if else if :
    Will help us execute multiple conditions at a time. 
                            Syntax : 
                            if(cond1){
                                //if block statements
                            }else if(cond2){
                                //else if block statements
                            }.
                            .
                            .
                            else{
                                //else block statements
                            }
  4. switch :
    unlike remaining conditional statements switch will not work on conditions.

    switch needs an input.

    1. input/ value
    2. case
                        syntax : 
                        switch(input){
                            case value : 
                                //block of code
                            break;
                            case value : 
                                ..
                            default: 
                                //block of code
                            break;
                        }

Loops :

Used to iterate a set/ block of code n number of times.

  • For loop
    Used to iterate a set statements n number of times. 
                        Syntax : 
                        for(init; condition; update){
                            //block of code
                        }
                        
                    flow : 
                        1.init - variable
                        2. condition - true 
                        3. Execution - block of code 
                        4. update -> goto 2
  • while loop :
    Used to iterate a set statements n number of times. Mainly we use while loop when we don't know the iteration count. 
                        syntax : 
                        init;
                        while(condition){
                            //block of code

                            update;
                        }
  • do-while loop :
    Used to iterate a set statements n number of times. It will execute atleast one time even thought the condition is false. 
                        syntax : 
                        init;
                        do{
                            //block of code

                            update;
                        }while(condition);
                    
                    steps : 
                        1. init
                        2. execute 
                        3. update 
                        4. condition -> true goto step 2
